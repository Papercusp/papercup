## What's gating v1.0

Exactly one phase: **6b**. Once componentId resolution + the Backstage-DI runtime land, the framework is v1.0-shaped and the Papercup reference plugin actually mounts as a plugin.

The contained pieces of 6b in priority order:

1. Wire the 7 not-yet-fired lifecycle hooks (`beforeMissionStart`, `onPostWorker`, `onPostValidator`, `onPostOrchestrator`, `onFeaturePassed`, `onProposalAccepted`, `onLoad`/`onUnload`)
2. Mount plugin `apiRoutes` (Hono `app.route('/api/plugins/<name>', plugin.apiRoutes)` iteration)
3. Build the typed-service DI container with capability proxy
4. Construct gated `PapercuspContext` and pass it to plugin hooks at fire time
5. Build `componentId` → lazy React registry; wire into `HarnessDashboard.tsx`

Items 1 + 2 unblock most non-UI plugins. Items 3 + 4 are the Backstage-DI runtime. Item 5 is the UI render piece.
