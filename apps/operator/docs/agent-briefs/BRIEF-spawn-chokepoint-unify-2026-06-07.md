# BRIEF — Unify agent spawns on one chokepoint (brain-decided admission + deterministic safety floor + durability)

**Type / mission.** Implementation. Agent spawns are governed unevenly across three separable layers — **admission** (is this spawn worth it now?), **pacing/safety** (don't breach the provider's hard limit), and **delivery/durability** (survive a crash, run once). Collapse them onto **one chokepoint**: the brain role makes the worth-it call via a typed, role-gated request; a thin deterministic floor enforces the hard ceiling + 429-pacing; a reusable durable-spawn wrapper makes autonomous spawns crash-safe. This is the whole of plan `unify-agent-spawn-chokepoint-2026-06-06` (Phases 0-4).
