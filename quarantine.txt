# quarantine.txt — flaky-test register
#
# Read by scripts/affected-tests.mjs at the start of every CI run. Two formats:
#
#   <workspace-name>                -> excluded from the affected run; logged as
#                                      quarantined (not silently skipped).
#   <workspace-name>::<file-glob>   -> per-file marker. The affected runner still
#                                      executes the workspace, but green-checkpoint
#                                      removes matching failing files from the v1
#                                      gate verdict and logs them as quarantined.
#
# Lines starting with `#` and blank lines are ignored.
#
# Policy (per spec §1.9):
#   - A test that's been flaky three times in seven days is auto-added.
#   - Any PR touching a quarantined test's source must address the flake
#     before merge (CODEOWNERS catches this).
#   - Empty quarantine list = the suite is healthy. The list grows in
#     PRs reviewed by humans, never silently.
