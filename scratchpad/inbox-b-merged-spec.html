Build order

Five steps, first one independent of the rest.

  1. Floor guard. min-height on .op-inbox__list and a chrome cap on .op-inbox__master, in split and stack mode both, with a regression test. Stops the collapse today, reviewable on its own, and guards the class from returning.
  2. The rail. New third column in split mode only — scopes, kinds, scope filters and the bulk card move out of .op-inbox__master. Stack mode (the ~360px chat sidebar) keeps its current composition, because there is no rail to move things into.
  3. The detail pane. Title heading, meta line, ~58-character body, and the six chips as a metadata rail.
  4. The resolver states. Rail summary for running and review; the run readout and the grouped report in the pane; Continue N retryable as a real control. Behaviour and persisted runs untouched, per D-001 on the two-pane plan.
  5. Then the two cleanups — one total instead of four, and the off-palette #3f7fd6 blue removed.
